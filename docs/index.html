Uma base para trocar de marca sem reescrever tela

O Rendra App separa a marca do componente: você muda cores, modelo, nome e logotipo, e o app inteiro acompanha.

Perguntas frequentes

Dúvidas comuns

O que é o Rendra App?

É um design system e boilerplate mobile em React Native (Expo), com Expo Router e NativeWind. Traz 65 componentes de UI, a navegação do app pronta, telas de exemplo, 3 modelos de marca e 4 paletas.

Posso usar em projeto comercial?

Sim. A licença é MIT: você pode usar, copiar, alterar e distribuir, inclusive em projetos comerciais, mantendo o aviso de copyright e o arquivo LICENSE. O crédito "Feito com Rendra" na tela é opcional.

Como troco a marca do app?

Com 4 cores, um degradê, um modelo, o nome e o logotipo, sem mexer em componente. Cada combinação de modelo e paleta tem um código, como T2-C3, que você informa no briefing.

Funciona no celular de verdade e na web?

Sim. O projeto roda no Expo Go (leia o QR code do terminal), em emuladores e no navegador. A demo desta página é o export web do próprio app, com os mesmos componentes.

Como uso com uma IA de código?

Cole o link do repositório numa IA de código (Claude Code, Codex, Cursor, Gemini ou Copilot). O AGENTS.md é o ponto de entrada: a IA conduz o briefing, planeja em etapas e roda os testes.

Os componentes são acessíveis?

Foram feitos para isso: toque mínimo de 44x44, foco visível, nada que dependa de hover e verificação automática com axe (WCAG 2.1 AA) em cada tela.
